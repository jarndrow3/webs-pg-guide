# webs-pg-guide

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面。这些页面内容涵盖不同主题，各自独立运行，彼此之间无特定关联。仓库本身不针对任何特定域名或网站，仅作为页面资源的集中存放与版本管理用途。

## 目录说明

```
webs-pg-guide/
├── pages/          # 存放所有独立 HTML 页面文件
├── assets/         # 页面引用的静态资源（如 CSS、JS、图片等）
└── README.md       # 本文件
```

- `pages/`：每个 HTML 页面为一个独立文件，命名遵循内容主题，便于识别。
- `assets/`：按页面或类型组织子目录，存放对应资源。

## 页面归档说明

- 所有页面均为独立的 HTML 文件，可直接在浏览器中打开查看。
- 页面可能引用 `assets/` 中的资源，需保持相对路径正确。
- 归档仅用于记录和展示，不提供在线服务或动态功能。
- 页面内容可能随时间更新或移除，请以仓库最新版本为准。

## 维护说明

- 本仓库由维护者不定期更新，新增页面或修正已有内容。
- 欢迎通过 Issue 提出建议或报告问题，但请注意：
  - 不涉及具体域名或网站的讨论。
  - 不包含营销、推广或诱导点击的内容。
- Pull Request 需遵循现有目录结构，并确保页面独立可运行。
